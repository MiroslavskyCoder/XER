# Модуль Видео Обработки (src/video)

## Введение

Модуль `src/video` фреймворка Flux предоставляет комплексное решение для работы с видеопотоками и изображениями в терминальном приложении. Он включает в себя продвинутые возможности рендеринга с использованием аппаратного ускорения (CUDA, Vulkan, Angle), гибкое управление кадрами через кэширование, импорт/экспорт, а также мощные инструменты для композитинга, маскирования и манипуляций с фрагментами видео.

## Ключевые возможности

*   **Аппаратный рендеринг:** Поддержка нескольких движков рендеринга:
    *   **CUDA:** Для высокопроизводительных вычислений на GPU NVIDIA.
    *   **Vulkan:** Современный кроссплатформенный графический API.
    *   **Angle:** Промежуточный слой, транслирующий OpenGL ES в нативные графические API (DirectX, Metal, Vulkan) для кроссплатформенности.
*   **Управление кадрами:**
    *   **Кэширование:** Эффективное хранение кадров (временных и постоянных) без автоматического удаления.
    *   **Импорт/Экспорт:** Чтение и запись кадров из/в кэш, а также другие источники/назначения.
*   **Композитинг и эффекты:**
    *   **Система микширования (Mix System):** Позволяет накладывать и смешивать несколько видеопотоков или изображений.
    *   **Система масок (Mask System):** Применение масок для выделения или скрытия определенных областей кадра.
    *   **Вырезание фрагментов:** Инструменты для точного вырезания частей кадра по заданным областям (`MaskPointsVector`).
    *   **Заполнение вне маски:** Возможность заполнять области, не покрытые маской, заданным цветом или изображением.
*   **Управление временными параметрами:**
    *   **Изменение FPS:** Контроль частоты кадров воспроизведения или вывода.
    *   **Управление временем (`Time ESP`):** Возможность замедления, ускорения, паузы или перемотки видеопотоков.
*   **Инструменты:** Предоставляет `Canvas` для рисования, `FragmentCutter` для манипуляций с областями.

## Архитектура модуля

Модуль `src/video` построен вокруг следующих основных компонентов:

*   **`VideoManager`:** Центральный оркестратор, управляющий всеми видеопотоками, рендерингом и обработкой.
*   **`VideoStream`:** Представляет собой отдельный видеопоток с его параметрами (источник, FPS, текущее состояние).
*   **`Frame` / `FrameData`:** Базовые структуры для представления данных кадра и его метаданных.
*   **`FrameCache`:** Система кэширования кадров.
*   **`FrameImporter` / `FrameExporter`:** Модули для чтения и записи кадров.
*   **`RenderingEngine`:** Абстракция для выбора и управления конкретным графическим API (CUDA, Vulkan, Angle).
    *   `CudaRenderer`, `VulkanRenderer`, `AngleRenderer`: Конкретные реализации рендеринга.
*   **`CompositingEngine`:** Управляет наложением слоев и смешиванием.
    *   `MixSystem`: Компонент для смешивания.
*   **`MaskSystem`:** Управляет масками и их применением.
    *   `MaskProcessor`: Обрабатывает применение маски к кадру.
    *   `MaskPoint`, `MaskPointsVector`: Структуры для определения масок.
*   **`FragmentCutter`:** Инструмент для вырезания частей кадра.
*   **`Canvas`:** Рабочая область для отрисовки и манипуляций с кадрами.
*   **`FPSController` / `TimeESPController`:** Модули для управления временными параметрами.
*   **`VideoUtils` / `VideoConstants` / `VideoConfiguration`:** Вспомогательные функции, константы и настройки.
*   **`VideoEffects`:** Модуль для применения различных визуальных эффектов.

## Рендеринг

Flux поддерживает несколько передовых графических API для высокопроизводительного рендеринга:

*   **CUDA:** Идеально подходит для задач, требующих интенсивных параллельных вычислений на GPU NVIDIA, таких как сложная обработка изображений или шейдерные эффекты.
*   **Vulkan:** Предоставляет низкоуровневый доступ к GPU, позволяя максимально оптимизировать производительность и использовать аппаратные возможности.
*   **Angle:** Обеспечивает кроссплатформенность, транслируя вызовы OpenGL ES в нативные API ОС, что делает приложения Flux совместимыми с широким спектром устройств.

Выбор рендеринга может быть настроен через `VideoConfiguration` или динамически во время выполнения.

## Работа с кадрами

### Кэширование

`FrameCache` хранит кадры в памяти или на диске (в соответствии с настройками `VideoConfiguration`). В отличие от типичных кэшей, здесь используется политика **"хранить без удаления"**, что означает, что кадры остаются доступными до явного освобождения ресурсов или очистки менеджером. Это полезно для приложений, где требуется повторный доступ к предыдущим кадрам (например, для эффектов, замедленной съемки).

### Импорт и Экспорт

*   **Импорт:** Кадры могут быть прочитаны из различных источников, включая:
    *   `FrameCache` (для быстрого доступа к уже загруженным или предыдущим кадрам).
    *   Файлы изображений или видео (через соответствующие импортеры).
    *   Другие модули Flux (например, генерация кадров).
*   **Экспорт:** Кадры могут быть экспортированы в:
    *   `FrameCache` (для последующего использования).
    *   Файлы изображений или видео.
    *   Отправлены на рендеринг через `RenderingEngine`.

## Манипуляции с кадрами

### Система Микширования (`MixSystem`)

Позволяет комбинировать несколько источников видео или изображений в один выходной кадр. Это может быть использовано для создания многослойных композиций, наложения видео друг на друга или объединения различных элементов интерфейса.

### Система Масок (`MaskSystem`)

*   **Определение масок:** Маски определяются с помощью `MaskPointsVector`, который задает контуры областей.
*   **Применение масок:** `MaskProcessor` использует эти маски для:
    *   **Вырезания фрагментов:** Только пиксели внутри заданной области маски остаются видимыми (`FragmentCutter`).
    *   **Заполнения вне маски:** Области, не покрытые маской, могут быть заполнены заданным цветом, прозрачностью или другим изображением.
    *   **Применения эффектов:** Эффекты могут быть применены только к определенным частям кадра.

## Управление временными параметрами

*   **FPS Controller:** Позволяет управлять частотой кадров. Это может быть полезно для:
    *   Замедления или ускорения воспроизведения.
    *   Обеспечения стабильной частоты кадров для плавного вывода.
    *   Синхронизации с другими компонентами.
*   **Time ESP Controller:** Предоставляет более тонкий контроль над течением времени:
    *   Пауза воспроизведения.
    *   Перемотка вперед/назад.
    *   Установка "тайм-кода" или смещения.
    *   Эмуляция "временного эскейпа" (например, для создания эффектов замедления или остановки времени).

## Использование

```cpp
#include "video/video_manager.h"
#include "video/frame_cache.h"
#include "video/mask_system.h"
#include "video/fragment_cutter.h"
#include "video/fps_controller.h"
#include "flux/core/flux_context.h" // Предполагается, что контекст доступен

using namespace flux;

// ... в главном модуле или при инициализации ...

// Получаем менеджер видео
auto& video_mgr = context.get_video_manager();

// Инициализация рендеринга (например, Vulkan)
video_mgr.init_renderer(RendererType::VULKAN);

// Создаем видеопоток (например, из файла)
auto stream = video_mgr.create_stream("input.mp4");
stream->play();

// Получаем доступ к кэшу кадров
auto& frame_cache = video_mgr.get_frame_cache();
frame_cache.store_frame("initial_frame", stream->get_current_frame()); // Сохраняем текущий кадр

// Создаем маску
MaskPointsVector mask_coords;
mask_coords.add_point({100, 100});
mask_coords.add_point({200, 100});
mask_coords.add_point({200, 200});
mask_coords.add_point({100, 200});

// Применяем маску и вырезаем фрагмент
auto processed_frame = video_mgr.process_frame(stream->get_current_frame(),
    [&](Frame& frame) {
        // Применяем маску, вырезаем фрагмент, заполняем вне маски
        MaskSystem mask_sys;
        mask_sys.apply_mask(frame, mask_coords, MaskAction::CUT_OUTSIDE, Color(0,0,0,0)); // Вырезать снаружи, заполнить прозрачным

        // Можно также применить эффекты или микширование
        // video_mgr.apply_effect(frame, EffectType::SEPIA);
        // video_mgr.mix_with(frame, overlay_frame);
    });

// Управляем FPS
auto& fps_ctrl = video_mgr.get_fps_controller();
fps_ctrl.set_target_fps(30.0); // Установить 30 кадров в секунду

// Управление временем (например, замедление в 2 раза)
auto& time_ctrl = video_mgr.get_time_esp_controller();
time_ctrl.set_playback_speed(0.5);
```

video_manager.h / video_manager.cc:

Главный класс, управляющий всем жизненным циклом видеопотоков, рендерингом и обработкой.
Оркестрирует работу RenderingEngine, FrameCache, MixSystem, MaskSystem и т.д.
video_stream.h / video_stream.cc:

Представляет собой отдельный видеопоток. Может содержать информацию о источнике, текущем кадре, FPS, статусе.
frame.h / frame.cc:

Базовый класс для представления одного кадра видео. Может содержать пиксельные данные, временную метку, разрешение.
frame_cache.h / frame_cache.cc:

Отвечает за хранение кадров.
Реализует политику “хранить кэш кадров без удаления”, то есть кадры остаются в кэше до тех пор, пока не будут явно удалены или не освободится память (если это предусмотрено).
Может взаимодействовать с FrameData для оптимизации хранения.
frame_data.h / frame_data.cc:

Более низкоуровневое представление данных кадра (например, буфер пикселей, формат, размер). Это может быть связано с форматами, используемыми CUDA/Vulkan/Angle.
frame_source.h / frame_source.cc:

Интерфейс или базовый класс для источников кадров (например, захват с камеры, чтение из файла, генерация).
frame_sink.h / frame_sink.cc:

Интерфейс или базовый класс для потребителей кадров (например, вывод на экран, запись в файл).
frame_importer.h / frame_importer.cc:

Отвечает за импорт кадров, включая чтение кадров из кэша (frame_cache) и, возможно, из других источников.
frame_exporter.h / frame_exporter.cc:

Отвечает за экспорт кадров, включая запись в кэш (frame_cache) или другие форматы.
rendering_engine.h / rendering_engine.cc:

Абстрактный класс или интерфейс для движков рендеринга.
Управляет выбором и инициализацией конкретного рендерера (CUDA, Vulkan, Angle).
render_target.h / render_target.cc:

Представляет собой область, на которую происходит рендеринг (например, текстура, поверхность, окно терминала).
cuda_renderer.h / cuda_renderer.cc:

Реализация рендеринга с использованием CUDA.
vulkan_renderer.h / vulkan_renderer.cc:

Реализация рендеринга с использованием Vulkan.
angle_renderer.h / angle_renderer.cc:

Реализация рендеринга с использованием Angle (для кроссплатформенного OpenGL/Direct3D).
compositing_engine.h / compositing_engine.cc:

Отвечает за объединение нескольких слоев или видеопотоков.
mix_system.h / mix_system.cc:

Система для смешивания (микширования) видеопотоков или изображений.
mask_system.h / mask_system.cc:

Управляет набором масок и их применением к видео.
mask_processor.h / mask_processor.cc:

Применяет маску к кадру, определяя, какие части кадра видимы, а какие скрыты.
mask_point.h / mask_point.cc:

Представляет одну точку маски (координаты).
mask_points_vector.h / mask_points_vector.cc:

Содержит коллекцию MaskPoint для определения формы маски.
fragment_cutter.h / fragment_cutter.cc:

Отвечает за вырезание фрагментов видео по заданным участкам (определяемым MaskPointsVector).
canvas.h / canvas.cc:

Представляет собой “холст”, на котором происходит отрисовка, наложение масок, вырезание фрагментов. Может быть связан с render_target.
fps_controller.h / fps_controller.cc:

Управляет частотой кадров (FPS) для видеопотока или всего приложения. Синхронизирует вывод кадров.
time_esp_controller.h / time_esp_controller.cc:

Управляет временными интервалами, паузами, замедлением/ускорением воспроизведения (“Time esp” — предполагаю, что это “time speed” или “time escape”).
video_utils.h / video_utils.cc:

Общие вспомогательные функции для работы с видео (например, преобразование цветовых пространств, обработка форматов изображений).
video_constants.h:

Константы, специфичные для модуля src/video/ (например, коды ошибок, размеры буферов по умолчанию).
video_configuration.h / video_configuration.cc:

Класс для настроек видеомодуля (выбор рендерера, пути к кэшу, настройки FPS, параметры маскирования).
video_effects.h / video_effects.cc:

Модуль для применения различных видеоэффектов (фильтры, цветокоррекция), которые могут работать с масками.
