# EngineDoctor: Комплексный анализатор и менеджер зависимостей

## Введение

EngineDoctor – это мощный фреймворк, предназначенный для глубокого анализа C++ проектов. Он автоматизирует задачи по поиску ошибок, диагностике проблем совместимости, управлению системными и библиотечными зависимостями, а также обеспечивает безопасное выполнение кода в изолированной среде.

## Основные возможности:

*   **Сканирование кода:** Анализ всех файлов и папок в указанном каталоге.
*   **Классификация ошибок:** Автоматическое разделение найденных проблем на категории, такие как `NoCorrect`, `NullEmpty`, `No0FIle`, `FileNoEmpty`, `DIcretory`, `FIleCallFailedFromRuntime`, `FatalStackError`.
*   **Анализ зависимостей:** Выявление установленных утилит и библиотек, обнаружение конфликтов, влияющих на запуск V8.
*   **Системный анализ:** Проверка зависимостей операционных систем (Linux, Windows, MacOS, OpenBSD и др.).
*   **SandboxSafe:** Безопасное выполнение кода без использования нейросетей.
*   **TransportWeakObserver:** Защищенный обмен метаданными для координации работы модулей.
*   **Package Handling:** Интеллектуальный поиск, фильтрация и установка необходимых библиотек.
