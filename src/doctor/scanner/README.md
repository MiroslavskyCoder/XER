# Модуль Сканирования

Модуль сканирования отвечает за обход файловой системы, поиск файлов и директорий, соответствующих заданным критериям, и извлечение необходимой информации (метаданных) для дальнейшего анализа.

## Основные компоненты:

*   **`FileScanner`**: Обработка отдельных файлов.
*   **`DirectoryScanner`**: Рекурсивный обход директорий.
*   **`ScanContext`**: Состояние и параметры текущего процесса сканирования.
*   **`ScanFilter`**: Правила и логика фильтрации объектов файловой системы.
*   **`ScanResultAggregator`**: Сбор и консолидация результатов сканирования.
*   **`FileMetadataExtractor`**: Извлечение метаданных (размер, дата модификации, права доступа, хеши и т.д.).

## Алгоритм сканирования:

1.  Инициализация `ScanContext` с заданными путями и опциями.
2.  Создание `ScanFilter` на основе конфигурации.
3.  Для каждого указанного пути:
    *   Если это файл, применяется `FileScanner` и `FileMetadataExtractor`.
    *   Если это директория, применяется `DirectoryScanner`.
4.  `DirectoryScanner` рекурсивно обходит поддиректории, применяя `ScanFilter`.
5.  Все найденные объекты (файлы и директории) передаются в `ScanResultAggregator`.

## Опции сканирования:

*   `--scan-path <path>`: Путь для сканирования.
*   `--exclude-dir <dir>`: Исключить директорию.
*   `--include-file-pattern <pattern>`: Включить файлы, соответствующие шаблону.
*   `--max-depth <depth>`: Максимальная глубина рекурсии.
