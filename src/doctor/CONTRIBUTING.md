# Руководство для контрибьюторов

Спасибо за интерес к внесению вклада в EngineDoctor! Мы приветствуем любые предложения и исправления.

## Как внести вклад:

1.  **Форкните репозиторий:** Создайте свою копию проекта.
2.  **Создайте новую ветку:** Для каждой новой функции или исправления создавайте отдельную ветку (`feature/my-new-feature`, `bugfix/issue-123`).
3.  **Внесите изменения:** Реализуйте свою идею, следуя [принципам проектирования](core/design_principles.md) и [стилю кода](CONTRIBUTING.md#стиль-кода).
4.  **Напишите тесты:** Убедитесь, что ваш код покрыт юнит-тестами.
5.  **Обновите документацию:** Если вы добавляете новые возможности, обновите соответствующую документацию.
6.  **Создайте Pull Request:** Откройте Pull Request в основной репозиторий.

## Стиль кода:

*   Используйте [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html).
*   Придерживайтесь однообразия в форматировании.
*   Добавляйте комментарии к сложному коду.

## Рецензирование:

Ваш Pull Request будет рассмотрен командой. Мы можем задавать вопросы или предлагать изменения. Пожалуйста, будьте готовы к обсуждению.
