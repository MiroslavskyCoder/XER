# Стратегии Анализа

EngineDoctor использует различные стратегии для проведения анализа кода. Выбор стратегии зависит от типа проекта, поставленных задач и доступных ресурсов.

## Доступные стратегии:

*   **`FullCodeAnalysis`**: Полный анализ всего кода, включая поиск ошибок, анализ зависимостей, проверку безопасности.
*   **`DependencyCheckStrategy`**: Фокус на анализе библиотечных и системных зависимостей, обнаружение конфликтов.
*   **`SecurityAuditStrategy`**: Проверка кода на уязвимости, анализ безопасности выполнения в песочнице.
*   **`PerformanceAnalysisStrategy`**: Оценка производительности кода, поиск узких мест.
*   **`V8CompatibilityStrategy`**: Специализированный анализ совместимости с V8.

## Выбор стратегии:

Стратегия анализа может быть выбрана при запуске EngineDoctor:

```bash
engine_doctor --scan /path/to/code --strategy FullCodeAnalysis
```

Или автоматически, на основе конфигурационных файлов проекта.

## Настройка стратегий:

Каждая стратегия может иметь свои параметры, которые можно задавать через конфигурационный файл или командную строку. Например, для `DependencyCheckStrategy` можно указать список интересующих библиотек.
