# Ядро EngineDoctor

Модули ядра EngineDoctor формируют основу фреймворка. Они отвечают за общую оркестрацию, управление жизненным циклом, конфигурацию и взаимодействие между различными компонентами.

## Структура:

*   **`engine_doctor_core`**: Главный класс, управляющий всем процессом.
*   **`engine_doctor_context`**: Содержит все объекты, необходимые для работы (конфигурацию, менеджеров).
*   **`engine_doctor_config`**: Управление настройками фреймворка.
*   **`engine_doctor_factory`**: Паттерн Factory для создания экземпляров модулей.
*   **`module_manager`**: Регистрация и управление жизненным циклом модулей.
*   **`event_bus`**: Система событий для асинхронного взаимодействия.
*   **`logger`**: Система логирования.
*   **`exceptions`**: Пользовательские типы исключений.
*   **`common_types`**: Общие структуры данных и перечисления.

## Взаимодействие:

Компоненты ядра предоставляют общий интерфейс для других модулей. `ModuleManager` регистрирует и предоставляет доступ к экземплярам других модулей через `EngineDoctorContext`. `EventBus` используется для неявной коммуникации, снижая прямую зависимость между компонентами.
