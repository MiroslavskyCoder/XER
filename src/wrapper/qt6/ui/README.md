# Qt6 UI

This directory is for widget-oriented wrappers and UI composition helpers.

Suggested contents:
- QWidget-based adapters
- layouts and controls
- dialog helpers
- application UI bootstrap code

Current runtime UI layer files:
- widget_factory.h / widget_factory.cc: constructors for Qt6 widget controls used by module runtime
- widget_ops.h / widget_ops.cc: generic text/value/checked/list operations for heterogeneous controls
